# CLAUDE.md

Personal ML project: credit card fraud detection (Kaggle dataset mlg-ulb/creditcardfraud)
using Random Forest, Optuna for tuning, and publishing to Hugging Face.
Built in small steps, one at a time.

## Working rules
- Code, comments, docstrings and README in English. Simple, readable style.
- Do NOT run git commit or git push; the user makes the commits.
- Do only what the current prompt asks, without anticipating future steps.
- When finished, list in a few lines what was created/changed.
